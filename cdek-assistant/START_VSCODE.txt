Быстрый запуск в Windows / VS Code

1. Установите Python 3.12+ с python.org, отметив Add python.exe to PATH.
2. Распакуйте архив репозитория. В VS Code откройте папку cdek-assistant,
   где находятся start.cmd, start.py и manage.py.
3. Дважды щёлкните start.cmd или в терминале VS Code выполните: .\start.cmd
4. Скрипт проверит Python, запустит сервер и откроет браузер.
   Обычный адрес: http://127.0.0.1:8080
   При первом запуске используйте открывшуюся одноразовую ссылку из окна запуска.
5. Создайте локального администратора. Пароль от 12 символов задайте сами.
6. Войдите. Форма запроса по товару доступна даже с пустой базой.
7. По предложению интерфейса загрузите основной ZIP материалов СДЭК, затем
   при необходимости ZIP дополнения по упаковке. Распаковывать их не нужно.
   Можно пропустить импорт и позже открыть «Проверка источников → Загрузить ZIP».
8. Администратору доступны перечень документов и поиск для проверки.
   Импортированные материалы остаются недопущенными к консультациям.
9. Не закрывайте окно сервера во время работы. Ctrl+C — остановка.
   Повторный запуск: снова start.cmd. Пользователи и документы сохраняются в data.

Не открывайте index.html и не используйте Live Server: это приложение с Python-сервером.
Учебные проекты в корне репозитория не относятся к помощнику.
Если браузер не открылся, скопируйте ссылку из окна запуска.
Если порт занят — закройте предыдущий сервер и повторите запуск.
Нет Python — установите его по подсказке окна и перезапустите VS Code.

Запасной запуск при установленном Python: python -X utf8 start.py
Сброс пароля: python manage.py user administrator --role admin
(Если ваш логин другой, укажите его. Используйте ту же папку данных.)

В коде нет ключей и аккаунтов по умолчанию. Облачный аккаунт не переносится локально.
Для настоящих ответов ИИ дополнительно нужны серверный ключ OpenAI и проверка
источников с индивидуальным допуском; поиск для проверки работает без модели.
Подробнее: README.md и LOCAL_VALIDATION.md.

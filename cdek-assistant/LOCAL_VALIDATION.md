# Проверка локального запуска — 3 ноября 2026

## Что изменено

- `start.cmd` для Windows ищет Python 3.12+ через `py -3` или `python`, включает UTF-8 и оставляет ошибку видимой.
- `start.py` проверяет SQLite FTS5, использует локальную `data` рядом с приложением, запускает Python-сервер на `127.0.0.1:8080`, печатает адрес и открывает браузер. Он сообщает о занятом порте и не подменяет сервер статической HTML-страницей.
- Первый локальный администратор создаётся в браузере по одноразовой ссылке из окна запуска. Пользователь сам выбирает пароль. Без одноразового кода регистрация недоступна; после первого аккаунта она закрывается. Код не передаётся в строке HTTP-запроса и удаляется из адресной строки браузера.
- ZIP материалов загружается администратором через интерфейс. Проверяются SHA256, тип пакета, пути, размер, порядок основного пакета и дополнения. Ошибка не заменяет рабочие файлы предыдущей версии.
- Пустая база явно обозначена; форма товара доступна после входа. Перечень документов и поиск для проверки доступны администратору. Все импортированные источники остаются недопущенными.
- MIME JavaScript задан явно, чтобы настройки реестра Windows не мешали загрузке скрипта с `nosniff`. Все JSON/Markdown пакетов читаются как UTF-8, независимо от системной кодировки Windows.

## Что действительно выполнено в браузере

Команда `node tests/first_run.cjs <stage2.zip> <packaging-addendum.zip>` запускала **настоящий `start.py`**, а не подготовленный сервер с уже созданными аккаунтами. Приложение копировалось в новую временную папку с пробелами и кириллицей (`VS Code СДЭК/cdek-assistant`); запуск шёл из другого текущего каталога. Папка `data`, аккаунты и база отсутствовали до запуска.

В Chromium выполнены:

1. Открытие первого запуска без одноразового кода: создание аккаунта недоступно.
2. Открытие ссылки запуска в той же вкладке; одноразовый код удаляется из URL.
3. Ошибка несовпадающих паролей, затем создание администратора с выбранным тестом случайным паролем через браузер. Прямого добавления пользователя в SQLite в этом сценарии нет.
4. Вход, открытие рабочего экрана, наличие формы товара, сообщение о пустой базе и предложение загрузить материалы.
5. Открытие административного перечня: пустое состояние объясняет загрузку документов.
6. Загрузка повреждённого ZIP: показана ошибка, база остаётся пустой.
7. Попытка загрузить дополнение первым: показано требование основного пакета.
8. Загрузка настоящего основного ZIP через браузер: проверены 315 файлов, показаны 206 источников, допущено 0.
9. Загрузка настоящего дополнения: проверены 11 файлов; версии 395/1037 и 227 строк упаковки добавлены без автоматического допуска.
10. Административный поиск «духи»: показаны фрагменты с пометкой «Только для проверки»; открыты документ 395 и история его версий.
11. Запрос по товару из рабочей формы: показано честное отсутствие допущенных источников; ответ модели не имитируется.
12. Сохранён [скриншот основного интерфейса после входа](docs/after-login.png). Проверена ширина 390 px без горизонтального переполнения.
13. Выход из аккаунта, остановка Python-сервера, повторный запуск того же `start.py` с той же локальной `data`.
14. Обычный вход после перезапуска; первый администратор повторно не предлагается. Сохранились 206 источников, административный поиск «упаковка» выдаёт результаты.
15. Ещё один выход и повторный вход. Ошибок JavaScript страницы не обнаружено.

Отдельный прежний браузерный набор `tests/browser.cjs` проверяет роль оператора, поиск администратора, защищённую загрузку оригинала, журнал, очередь и сообщения при неработающем API/незагрузившемся JavaScript.

## Остальные проверки и ограничения

- 27 Python unittest прошли без пропусков в этой среде: включая одноразовую регистрацию, запрет повторной регистрации, вход, MIME JS независимо от реестра, занятый порт, ZIP traversal/Windows-пути, откат неудачного импорта и прежние проверки допуска/цитат.
- Среда выполнения — Linux, Python 3.12, Chromium через Playwright. **Настоящая Windows и исполнение `start.cmd` здесь не проверены**. Проверен общий Python-мастер и весь браузерный путь, в том числе путь установки с кириллицей/пробелами. Это не равнозначно испытанию Windows launcher на устройстве пользователя.
- OpenAI не подключался; реальные ответы модели и допуск источников в эту проверку не входят. Интерфейс, импорт и поиск для проверки работают без ключа.
- Учебные файлы и проекты в корне репозитория не менялись. Все изменения находятся внутри `cdek-assistant`.
- Пароли тестов случайные и относятся только к удалённой после проверки временной базе. Локальные аккаунты пользователя и облачный аккаунт не перезаписывались.
